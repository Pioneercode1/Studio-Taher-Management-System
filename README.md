# Studio Taher Management System

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)

**Studio Taher Management System** is a desktop application developed to manage and organize the daily operations of **Studio Taher**, including customer management, bookings, services, work records, and reporting.

The project was originally started in **2015** and has been designed to provide a practical and organized solution for managing studio operations and customer information.

## Project Overview

The system provides a centralized solution for storing and managing customer data, tracking bookings and services, organizing daily work, and generating professional reports.

It is built using **VB.NET** with **Microsoft SQL Server** as the database platform and **ReportViewer** for generating and displaying reports.

## Key Features

- Customer information management.
- Customer registration, editing, searching, and data management.
- Booking and appointment management.
- Service and work management.
- Linking bookings and services to customers.
- Searching and retrieving customer records.
- Organizing daily studio operations.
- Generating customer and business reports.
- Filtering reports by customer name.
- Previewing and printing reports using **ReportViewer**.
- Centralized data storage using SQL Server.

## Reporting

The application uses **ReportViewer** to generate, display, and print professional reports.

Examples of supported reports include:

- Customer Information Reports.
- Customer Booking Reports.
- Bookings by Date.
- Bookings by Customer.
- Services and Work Reports.
- Customer Activity Reports.
- Detailed reports filtered by customer name.

## Technologies Used

| Technology | Purpose |

## Database

The system uses **Microsoft SQL Server** as its primary database management system.

The database is designed to organize and maintain information related to customers, bookings, services, orders, payments, and other studio operations.

Example database entities include:

- `Customers`
- `Bookings`
- `Services`
- `Orders`
- `Payments`

The database structure can be extended according to the operational requirements of the studio.
